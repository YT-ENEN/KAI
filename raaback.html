VOTE AUDIT

UID SECURITY

UID 管理

查詢投票與參賽身份。封鎖 UID 後將無法重新登記或投票；解除封鎖可恢復使用。

UID名稱身份隊伍賽季狀態原因操作
AWARD CONTROL

獎項設定

控制獎項是否啟用、能否由參賽者自行申請、能否進行公開投票。主辦方獎項預設不開放公開申請與投票。

EVENT SETTINGS

活動設定

控制前台活動狀態、公告、直播與公開資料。不需要修改前端 HTML 就能切換。
